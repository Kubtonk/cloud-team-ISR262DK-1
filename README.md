# Cloud Team Project: каталог облачных сервисов

> Учебный проект по дисциплине **«Основы облачных технологий»**, группа ISR262DK-1. Командная работа в GitHub и документирование средствами Markdown.

## О проекте

Проект представляет собой **каталог облачных сервисов**: в нём сравниваются модели обслуживания **IaaS, PaaS и SaaS** и приводятся примеры популярных облачных сервисов по каждой категории. Каталог ведётся в формате Markdown, хранится в GitHub и изменяется командой через Issues, ветки и Pull Request с обязательным Code Review.

Цель документации — чтобы новый участник за несколько минут понял, что содержит каталог, как он устроен и как внести в него изменения.

## Архитектура

Проект не содержит исполняемого кода: это документационная система, в которой GitHub выступает платформой хранения, проверки и публикации.

| Компонент | Назначение | Связь с другими компонентами |
|-----------|------------|------------------------------|
| **README.md** | Точка входа: описание проекта, структура, правила работы | Ссылается на документы каталога в `docs/` |
| **docs/models-comparison.md** | Таблица сравнения IaaS, PaaS, SaaS (что предоставляет провайдер, кто управляет ОС и т. д.) | Категории из таблицы используются в каталоге примеров |
| **docs/services-examples.md** | Примеры облачных сервисов по категориям | Каждый пример относится к модели из сравнения |
| **GitHub (Issues, ветки, Pull Request)** | Постановка задач, изолированная работа, Code Review | Любое изменение файлов каталога проходит через PR в `main` |

Схема взаимодействия:

```text
Issue (задача) → ветка feature/* → commit → Pull Request → Code Review → merge в main
                                      ↓
                         README.md, docs/*.md (каталог)
```

## Структура репозитория

```text
cloud-team-ISR262DK-1/

├── REPORT.md                 # отчёт о выполненной работе

    ├── models-comparison.md  # сравнение IaaS / PaaS / SaaS
    └── services-examples.md  # примеры облачных сервисов
```

## Краткая справка по моделям

| Модель | Что предоставляет провайдер | Кто управляет ОС | Пример использования |
|--------|-----------------------------|------------------|----------------------|
| **IaaS** | Виртуальные машины, сети, хранилище | Пользователь | Развёртывание собственного сервера |
| **PaaS** | Платформа для разработки и запуска приложений | Провайдер | Публикация веб-приложения без настройки сервера |
| **SaaS** | Готовое приложение через браузер | Провайдер | Почта, офисные пакеты |

Полная версия — в [docs/models-comparison.md](docs/models-comparison.md), примеры сервисов — в [docs/services-examples.md](docs/services-examples.md).

## Используемые технологии

- **Git** — система контроля версий;
- **GitHub** — хранение репозитория, Issues, Pull Request, Code Review;
- **Markdown** — язык разметки для всей документации.

## Как работать с проектом

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/Kubtonk/cloud-team-ISR262DK-1.git
   cd cloud-team-ISR262DK-1
   ```
2. Открыть документы каталога в папке `docs/` (на GitHub они отображаются автоматически, локально — любым редактором или предпросмотром Markdown).
3. Создать ветку для изменений:
   ```bash
   git checkout -b feature/my-change
   ```
4. Внести правку, сохранить и зафиксировать:
   ```bash
   git add .
   git commit -m "docs: краткое описание изменения"
   git push -u origin feature/my-change
   ```
5. Открыть Pull Request в `main` и дождаться Code Review.

> ⚠️ Пароли, токены и ключи доступа в репозиторий не добавляются.
